About Mica

Mica is an open source, lightweight assistant running on your computer, not using heavy AI models, but relying on the community to expand its capabilities.

Its full code is written in Python, a language easy to understand for beginners and complete for experienced programmers.

Its EpiCenter library handles all the complex plugin handling, allowing anyone to easily add functionalities.

It is shipped with a comprehensive array of capabilities, and its core-less architecture allows users to tailor or replace everything it does by default.

Its base plugins allow anyone to develop functionalities and link them to natural language queries, enabling users to command the assistant without unfriendly bash-style prompts.

Mica's mascot !

The end goal is to create an open-source smart assistant for your home, desktop, smartphone that YOU have control on

Getting Started

Prerequisites

To run Mica, you have to install these first, everything there is open source and free.

Python The language in which Mica is written
Minimum version is Python3.8, get it here: https://www.python.org/downloads/

Git The way Mica is distributed and its plugins are shared, get it here: https://git-scm.com/install/

Installing via Git

Open a command prompt, and type:

Running the install script

In the same command prompt, type:
cd Mica
And then:
python setup.py
This command will install the packages necessary for Mica and create a handy shortcut ! (if you use Windows at least...)

Starting Mica !

If you are using windows, a shortcut has been created in the new folder, simply click it !

Alternatively, if you prefer to use the command prompt:
python -m mica

Mica is set as a module, so it can be started from anywhere!

Feeling like Mica needs to do more ?
Download and upload plugins !

Download plugins

Mica's default plugins allow to easily add plugins from Github

Simply look for github repositories with the topic: mica-assistant-plugin, get the download link (finishing in .git)

Then, tell Mica:

> add plugin plugin-link
This will download and activate the plugin, all automatic !

Share with the community

You created a plugin that others would like ? Everyone can upload plugins on Github and make them available to the community

Simply publish a public Github repository, and set the topic of the repo to mica-assistant-plugin.
To add a topic to your repository, you can follow this guide

Things to keep in mind:
  • The repository must be named the same as the plugin
  • The plugin must be in the root of the repository
  • If the plugin relies on other plugins to be downloaded, you can create a file named "required-plugins.txt", with one plugin name per line
As soon as you upload it to github, every other user will have access to it !

Main Features

Plugin System

The Secret to Mica's core-less architecture it its plugins, no need to have any core capabilities if everything can be made optional !
This way, each plugin adds or changes functionalities, making Mica completely customisable !
If you like a plugin but thinks it needs tweaking, you can rewrite any method by loading the old plugin first, then by loading a plugin just containing your new method, this will simply overwrite the one in the old plugin.
Mica loads every plugin found in its configuration file "mica_config.json", so its easy to changes which plugins are loaded !
If your plugin needs functionalities from another plugin, simply add the line:

required_plugins = ["required plugin name", ]
and the bootloader will automatically reorganise the loading order to make sure that the required plugins are loaded before.

Call methods with natural language

While not relying on a language model, Mica can understand natural text, by relying on natural languages templates.
Such a template looks like this:

"auto_engine": [
"Open {browser} and search {*query}",
"On {browser} search {*query}",
"with {browser} search/open {*query}",
"open/search/play {*query} on/with {browser}"
],
Each of these sentences will start the method "auto_engine", the words between brackets are the arguments that will be fed to the method.
When there is an asterisk before the word, it means this argument can take text of multiple words, this is useful if you dont know how long this output is
When words are separated by a /, it means each of these words are valid for this sentence !

To link your own sentences to your plugin's functionalities, you can create additional template files, simply create a json file with the same structure as plugins/nlp/core_templates.json and in your plugin, call this method:

self.load_template_file("path to the json file")
and mark nlp-core as a required plugin !

If you want to add templates without restarting everything, you can tell Mica:

> Append your-template to your-method
and Mica will edit the right template file for you !

If you wonder what Mica can say at any moment, just say:

> What can I say ?

Community Workshop

Mica leverages Github's code sharing capability to create a fully integrated community workshop !
There, users can share functionalities, interfaces, themes, and anything they can think of in the form of plugins
Mica provides natural language commands that allow non developers to download these community-made plugins without headaches !
